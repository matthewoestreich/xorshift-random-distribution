# xorshift128+ Random Distribution

[Live Demo](https://matthewoestreich.github.io/xorshift-random-distribution/)

We use an exact clone of the `Math.random` implementation used by Chrome `v154.0.8037.98 (Official Build) (x86_64)`.

# Commands

## Build

```
npm run build
```

## Dev Server

```
npm run dev
```

## Preview Build

```
npm run preview
```
