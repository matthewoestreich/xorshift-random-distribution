XorShift128+ Random Distribution

Implementation

We use an exact clone of the Math.random implementation used by Chrome v154.0.8037.98 (Official Build) (x86_64). You can find the source code of our implementation here.

Options

You can seed the implementation with any number you like, or use a random seed.

Seed must be a number.

How many numbers should we generate? Max is 2,000,000.

Count must be a number less than or equal to the max.

Charts

This heatmap shows how often consecutive random numbers fall within different ranges. It does not show whether the individual numbers are uniformly distributed on their own. The X-axis represents a random number (random[i]), and the Y-axis represents the next (random[i + 1]). Each square shows how many times a pair of numbers falls within the corresponding ranges.
